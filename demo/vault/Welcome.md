# Welcome to the SecondBrain demo

This is a public demo instance of [SecondBrain](https://github.com/) — a semantic memory system that turns an Obsidian vault into an intelligent, searchable knowledge base.

The vault you're browsing belongs to **Brett Johnson**, a fictional tech consultant. Brett runs two client engagements ([[Northgate Health Migration]] and [[Lakeside Bank AI Advisory]]), works on a side project ([[Pantry]] — a recipe app), and keeps notes on cooking, running, and tech he's reading.

## What to try

- **Chat:** ask the vault questions. Try _"What's blocking the Northgate engagement?"_ or _"What recipes has Brett been working on?"_
- **Tasks:** look at the aggregated task tree — tasks live in daily notes and are pulled into a single view.
- **Calendar:** events from daily notes, laid out by week.
- **Knowledge Library:** paste a URL on the Capture page to see the safety auditor + wiki compilation pipeline in action.
- **Admin:** see real-time AI cost tracking and OpenTelemetry traces for every LLM call.

## Notes for visitors

- This is a shared demo. LLM calls are rate-limited (10 chat queries per hour per visitor) to keep costs predictable.
- Any captures you make stay in this demo instance. Treat it as ephemeral.
- The vault is fabricated — Brett Johnson is a persona, the companies are fictional.

Enjoy poking around.
